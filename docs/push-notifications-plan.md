# Push-уведомления в PWA «Цифра» — план на будущее

> **Не реализовано.** Триггер: **«Давай к push»** / **«уведомления в приложении»** / **«пуши»**.

## Идея

Web Push для установленной PWA: уведомления на телефон/ПК даже когда приложение закрыто (напоминания, админ-алерты, «обновился контент»).

## Что уже есть в проекте

- PWA: `app/manifest.ts`, установка «На экран Домой».
- Service worker: `public/sw.js` (сейчас только кэш и обновление версии).
- Регистрация SW: `components/PwaRegister.tsx`.
- HTTPS на Vercel — условие для push выполнено.

Push **ещё не подключён** — нужно расширить SW и добавить backend.

## Как это работает (кратко)

1. Пользователь разрешает уведомления в браузере.
2. Клиент подписывается через `pushManager.subscribe` (VAPID), отправляет подписку на API.
3. Сервер сохраняет подписку (привязка к email из сессии).
4. По событию сервер шлёт push (`web-push` + VAPID-ключи).
5. SW обрабатывает `push` и `notificationclick`, показывает уведомление.

## Что нужно сделать

| Часть | Задача |

| Клиент | Запрос разрешения, подписка, отправка на API, UI «Включить уведомления» |

| Триггеры | Cron Vercel, кнопка в админке или webhook после деплоя |

## Примеры сценариев

- Напоминание пройти тест (раз в N дней).
- Админу: сотрудник не сдал тест / низкий балл.
- «Обновилась справка или скрипт» после релиза.
- Не путать с **локальными** уведомлениями на открытой странице — они не заменяют Web Push.

## Ограничения

- **Android / Chrome, Edge, Firefox (ПК)** — обычно работает для установленной PWA.
- **iPhone** — Web Push у **установленной** PWA с **iOS 16.4+**, если пользователь разрешил; только Safari без «На экран Домой» — слабо или никак.
- Пользователь может отключить уведомления в настройках ОС.
- Нужен сервер, который шлёт push; одного фронта недостаточно.

## Оценка трудозатрат

- **MVP** (кнопка включения + тестовый push из админки): ~1–2 дня.
- **Продакшен** (подписки по пользователям, отписка, расписание, логи, проверка iOS): ~3–5 дней.

## Перед стартом уточнить

- Когда: по расписанию, по событию, вручную из админки.
