# Тренажёр звонков (AI-обучение менеджеров) — план на будущее

> **Не реализовано.** Триггер: **«Давай к тренажёру звонков»** / **«вернёмся к обучению менеджеров»**.

## Идея

1. Записи реальных звонков менеджер–клиент (этап квалификации ОГЗ) → расшифровка → **база знаний** (хорошие/плохие фразы, привязка к шагам скрипта).
2. В web PWA — режим **обучения**: менеджер ведёт диалог в микрофон, приложение **подсказывает** ответы и ведёт по скрипту.
3. После «звонка» — **оценка** и список ошибок.

## Рекомендуемый старт (когда начнём)

- **Этап 0:** 10–20 записей + разметка РОПом по шагам `script-engine` / `scoring`.
- **MVP:** симуляция (не живой клиент), не подсказки на реальном звонке в v1.
- **Каркас:** жёсткий скрипт + RAG по расшифровкам + оценка через те же правила воронки/JTBD, что CallWizard.

## Архитектура (черновик)

```
Микрофон (PWA) → STT → backend → RAG (база знаний) + LLM
  → подсказка / реплика «клиента» / оценка шага
Сессии тренировок в Redis/DB; политика хранения аудио — отдельно
```

Долгие сессии STT/LLM — не на Vercel serverless без worker; отдельный API или воркер.

## Режимы

| Режим | Описание | Приоритет |
|-------|----------|-----------|
| Симуляция | Клиент — бот/сценарий, менеджер в микрофон | v1 |
| Коуч на живом звонке | Подсказки во время реального разговора | v2+ |

## Оценка после звонка

- Пройдены ли шаги скрипта (бюджет, срок, ЛПР, регион…).
- Соответствие `QualificationState` / воронке / нецелевому (как `calculateFunnel`).
- Сравнение с эталонными фразами из базы знаний.
- Итог: балл + ошибки + 2–3 рекомендации.

## Риски

- Согласие на запись и хранение; обезличивание.
- Качество STT (шум, связь).
- Стоимость API (STT + LLM) — лимиты на пользователя.
- LLM не должен подменять правила скрипта — каркас скрипта главный.

## Связь с текущей PWA

- `CallWizard`, `lib/script-engine.ts`, `lib/scoring.ts`, JTBD-фразы.
- Статистика админа — опционально: баллы тренировок.
- amoCRM — для реальных итогов, не обязательно для симуляции.

## Этапы реализации (когда решим)

0. Расшифровки + разметка  
1. База знаний (ситуация → хорошо/плохо)  
2. Текстовый тренажёр (без голоса)  
3. Голосовая симуляция одного сценария  
4. Оценка + отчёт  
5. Несколько сценариев (целевой, нецелевой А/Б/В)
