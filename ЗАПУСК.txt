  Аналитическая платформа «Цифра» — как запустить
═══════════════════════════════════════════════════════

СПОСОБ 1 (проще всего)
  Дважды щёлкните файл:  dev.cmd
  Откройте браузер:       http://localhost:3002

СПОСОБ 2 — PowerShell
  cd C:\Users\Windows\cifra-platform
  npm.cmd run dev

  (не используйте "cd /d" — это только для cmd)
  (не "npm run dev", а "npm.cmd run dev" — обходит блокировку)

СПОСОБ 3 — классическая командная строка (cmd)
  cd /d C:\Users\Windows\cifra-platform
  npm run dev
