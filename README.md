# Аналитическая платформа «Цифра»

PWA для квалификации лидов по скрипту ОГЗ: установка на смартфон, пошаговый мастер, воронки CRM, JTBD.

## Возможности

- Установка на главный экран (Android / iPhone)
- В браузере — экран «Установить приложение»; в установленном приложении — только рабочий интерфейс
- Авторизация по email из белого списка
- Одна сессия на аккаунт (новый вход завершает предыдущий)
- Управление доступом в `/admin`

## Локальный запуск (Windows)

```bat
cd C:\Users\Windows\cifra-platform
npm.cmd install
npm.cmd run dev
```

Или дважды щёлкните **`dev.cmd`**.

Откройте: **http://localhost:3002**

Скопируйте `.env.example` → `.env` и укажите `ADMIN_EMAIL`.

## Публикация на GitHub

1. Создайте репозиторий на GitHub (например `cifra-platform`).

2. В папке проекта:

```bat
cd C:\Users\Windows\cifra-platform
git init
git add .
git commit -m "Initial commit: PWA Цифра"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/cifra-platform.git
git push -u origin main
```

Файл `data/store.json` **не попадает** в Git (личные почты). На сервере создастся из `ADMIN_EMAIL`.

## Деплой в интернет (ссылка для менеджеров)

PWA и установка работают только по **HTTPS**.

Рекомендуется [Vercel](https://vercel.com) (бесплатный тариф):

1. Импортируйте репозиторий GitHub в Vercel.
2. Environment Variables:
   - `ADMIN_EMAIL` = `sovarovsky@gmail.com`
   - `SESSION_SECRET` = длинная случайная строка
   - `PORT` = `3002` (для Vercel не обязателен — порт задаёт платформа)
3. Deploy → получите URL вида `https://cifra-xxx.vercel.app`.

Эту ссылку отправляйте менеджерам. На телефоне откроется страница входа с кнопкой **«Установить приложение»**.

> **Важно:** на Vercel файловое хранилище `data/store.json` сбрасывается при перезапуске. Для продакшена с постоянной базой используйте VPS (Railway, Timeweb, Selectel) или подключите БД. Для пилота на Vercel добавляйте почты через `/admin` после каждого cold start или используйте VPS.

## PWA: поведение

| Режим | Что видит пользователь |
|--------|-------------------------|
| Ссылка в браузере | Блок «Установить приложение» + «Продолжить в браузере» |
| Установленное приложение | Только вход и скрипт, без кнопки установки |

**iPhone:** Safari → Поделиться → «На экран Домой».  
**Android:** Chrome → «Установить приложение».

## Администрирование

`ADMIN_EMAIL` в `.env` — главный админ. Страница **Доступ** (`/admin`): добавить / удалить почты, выдать роль админа.

## Структура

- `lib/script-engine.ts` — шаги скрипта
- `lib/scoring.ts` — воронки и приоритет
- `data/jtbd.json` — JTBD
- `data/store.json` — разрешённые почты (локально, не в Git)
